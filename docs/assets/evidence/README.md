# Visual verification evidence

This directory preserves reviewed screenshots and measurement records referenced by project reports. Files were copied unchanged from their original capture locations; `playwright/` and `ui-review/` retain the original grouping and filenames. Dates and tested versions are documented in the corresponding reports.

New browser captures, traces, execution artifacts and temporary reports belong in the ignored root `output/` directory. Copy only reviewed, credential-free evidence here and link it from a report. Current README illustrations are maintained separately in `docs/assets/screenshots/`.
